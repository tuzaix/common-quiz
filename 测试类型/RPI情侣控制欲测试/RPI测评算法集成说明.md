# RPI 关系占有欲指数测评：算法集成说明文档

本手册旨在帮助开发人员将 RPI 测评计分算法集成到通用的测评平台中。

## 1. 核心数据结构

### 1.1 计分量表 (Scale)
- **类型**：李克特 7 点量表 (Likert 7-point scale)
- **分值范围**：1 (完全不符合) 到 7 (完全符合)
- **中位值**：4.0 (一般/说不清)

### 1.2 维度定义与权重 (Dimensions)
| 维度 ID | 维度名称 | 建议权重 | 包含题目数 |
| :--- | :--- | :--- | :--- |
| **Control** | 控制欲 | 30% (0.3) | 10 题 |
| **Jealousy** | 嫉妒强度 | 25% (0.25) | 10 题 |
| **Dependency** | 情感依赖 | 20% (0.2) | 10 题 |
| **Insecurity** | 关系不安全感 | 25% (0.25) | 10 题 |

---

## 2. 计分算法逻辑

### 步骤一：预处理（正反向计分）
对于每一道题，系统需要根据 `direction` 属性决定其最终分值：
- **正向题 (positive)**：`Score = RawValue`
- **反向题 (reverse)**：`Score = (Min + Max) - RawValue`
  - *注：在 1-7 量表下，反向分 = 8 - 原始分。*

### 步骤二：计算维度分 (Dimension Score)
维度分采用 **加权平均值** 算法。
- **公式**：`维度分 = Σ(题目分 × 题目权重) / Σ题目权重`
- **结果范围**：1.00 - 7.00（保留两位小数）

### 步骤三：计算总体指数 (Overall RPI)
总体指数采用 **维度加权汇总** 算法。
- **公式**：`总分 = Σ(维度分 × 维度权重) / Σ维度权重`
- **结果范围**：1.00 - 7.00

---

## 3. 报告解读与建议逻辑

### 3.1 分段解读标准
| 分数区间 | 程度 | 解读建议 |
| :--- | :--- | :--- |
| 1.0 - 2.5 | 极低 | 关系边界清晰，高度信任。 |
| 2.5 - 4.0 | 中低 | 存在轻微占有倾向，通常属于正常健康范畴。 |
| 4.0 - 5.5 | 中高 | 占有倾向明显，建议开始关注互动模式。 |
| 5.5 - 7.0 | 极高 | 占有倾向强烈，可能存在潜在的关系压力或风险。 |

### 3.2 建议匹配规则
1. **排序**：将所有维度得分按降序排列。
2. **触发点**：
   - 得分 **≥ 4.0** 的维度：被视为“风险点”，系统应展示该维度的前 2 条深度改进建议。
   - 得分 **< 4.0** 且为最高分的维度：展示 1 条通用建议作为参考。

## 4. JS 集成代码示例

您可以直接引用 [rpi_scoring_logic.js](./rpi_scoring_logic.js) 中的 `calculateRPI` 函数：

```javascript
// 假设您已加载题库 json 到 bankData 变量
const userAnswers = { "C_01": 5, "C_09": 2, "J_01": 6 ... };

const result = calculateRPI(
  userAnswers, 
  bankData.items, 
  bankData.recommendations
);

console.log("最终得分:", result.overall_index);
console.log("维度明细:", result.dimension_scores);
```

## 5. 注意事项
- **检测项过滤**：题库中包含 `ATTN_01` 等检测项（direction: "check"），这些题目不参与任何计分，仅用于判断答题认真程度。
- **零分处理**：如果用户跳过了某个维度的所有题目，该维度分应计为 0，且不应计入总分权重的分母中。
