# 通用测试平台产品需求文档 (PRD)

## 1. 项目概述
### 1.1 背景
当前市场存在大量同类型的心理测试、趣味测试、知识竞赛等需求。为了降低重复开发成本，需要构建一个“通用测试构建平台”。该平台允许通过配置化的方式，快速生成不同主题、不同逻辑的测试网站。

### 1.2 目标
- **零代码/低代码生成**：通过后台配置题目、文案、逻辑，即可生成前端测试页面。
- **高度可定制**：支持自定义主题色、背景图、结果页样式、分享卡片样式。
- **多种计分模型**：涵盖累加计分、维度分析（雷达图）、跳转逻辑（分支剧情）、MBTI 类型推导等。
- **完善的变现与传播**：内置卡密验证系统、微信分享图生成功能。

## 2. 用户角色
| 角色 | 描述 | 核心功能 |
| :--- | :--- | :--- |
| **管理员 (Admin)** | 平台的运营者或创作者 | 创建项目、管理题目、配置逻辑、生成卡密、查看数据。 |
| **测试用户 (User)** | 参与测试的终端用户 | 答题、支付/验证（可选）、查看结果、保存分享图。 |

## 3. 核心功能模块

### 3.1 项目管理中心
- **新建项目**：选择模板（心理测试、知识问答、趣味跳转）创建新项目。
- **基础配置**：
    - 项目名称、简介、封面图。
    - 全局主题色（Primary Color）、背景图/背景色。
    - 字体设置。
- **发布管理**：一键发布/下架，生成独立访问链接（如 `domain.com/quiz/mbti`）。

### 3.2 题目管理引擎
- **题型支持**：
    - 单选题（文本/图片）。
    - 多选题。
    - 量表题（如李克特 5 点量表）。
    - 滑动条打分。
- **题目属性**：
    - 关联维度（如“外向性”、“神经质”）。
    - 关联分数（该选项得几分）。
    - 跳转逻辑（选 A 跳第 5 题）。
    - 题目乱序开关。

### 3.3 逻辑配置中心 (核心差异化)
管理员可选择计分策略：
1.  **简单累加型**：总分 = 各题得分之和。适用于：抑郁症自测、知识竞赛。
2.  **多维度分析型**：分别计算各维度得分，生成雷达图/柱状图。适用于：大五人格、心理年龄。
3.  **类型推导型**：根据各维度得分高低组合得出结论。适用于：MBTI、霍兰德职业测试。
4.  **公式计算型**：支持输入自定义 JavaScript 简易公式（如 `BaseScore + (A_Score * 1.5)`）。

### 3.4 结果页装修
- **结果规则**：
    - **分段匹配**：0-60 分显示“不及格”，60-80 分显示“良好”。
    - **最大维度匹配**：哪一个维度分最高，就显示该维度的文案。
- **展示组件**：
    - 文本模块（标题、详情）。
    - 图表模块（雷达图、饼图、折线图）。
    - 建议模块（根据结果推荐内容）。
- **分享卡片编辑器**：
    - 可视化拖拽布局（或基于 HTML 模板配置）。
    - 自定义背景、二维码位置、结果文案占位符。

### 3.5 访问控制与变现
- **公开模式**：所有人可测。
- **卡密模式**：需输入有效卡密才能查看结果或开始测试。
- **设备限制**：限制同一卡密可在多少台设备使用。
- **有效期控制**：设置卡密激活后的有效时长。

## 4. 业务流程图 (User Flow)

### 4.1 管理员流程
1.  创建项目 -> 2. 配置题目 -> 3. 设定计分逻辑 -> 4. 装修结果页 -> 5. 发布上线 -> 6. 生成卡密(可选)

### 4.2 用户流程
1.  访问首页（Landing Page） -> 2. 开始答题 -> 3. 提交答案 -> 4. (卡密验证拦截) -> 5. 计算结果 -> 6. 展示结果页 -> 7. 生成分享图

## 5. 非功能需求
- **移动端优先**：所有生成页面必须完美适配 iOS/Android 手机及微信内置浏览器。
- **高性能**：结果计算在前端完成（或 Serverless），无延迟。
- **SEO 友好**：支持 SSR 或预渲染（针对 Landing Page）。
